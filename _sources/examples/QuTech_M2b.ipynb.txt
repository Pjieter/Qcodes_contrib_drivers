    "## QuTech M2b Voltage Preamplifier\n",
    "\n",
    "The M2b is a low-noise voltage amplifier designed for use in the IVVI rack system. It amplifies small voltage signals with selectable gain.\n",
    "\n",
    "**Key Features:**\n",
    "- Voltage gains: 100, 1k, 10k (V/V)\n",
    "- DC or AC coupling mode\n",
    "- Compatible with IVVI rack system\n",
    "\n",
    "**Documentation:** https://qtwork.tudelft.nl/~schouten/ivvi/doc-mod/docm2b.htm"
   ]

    "### Using VoltageParameter for Measurements\n",
    "\n",
    "The `VoltageParameter` class automatically converts amplified voltage measurements back to the input voltage using the M2b's total gain."
   ]
  },
  {
   "cell_type": "code",

   "id": "129489ed",

    "from qcodes.instrument_drivers.mock_instruments import DummyInstrument\n",
    "\n",
    "# Create a mock DMM (digital multimeter) that simulates measuring the M2b output\n",
    "# In a real setup, this would be an actual DMM like Keysight 34465A\n",
    "dmm = DummyInstrument(name=\"dmm\", gates=[\"voltage\"])\n",
    "\n",
    "# Create VoltageParameter that links voltage measurement to M2b\n",
    "voltage_param = VoltageParameter(\n",
    "    measured_param=dmm.voltage,  # Use the DMM voltage parameter\n",
    "    voltage_amplifier_instrument=preamp,\n",
    "    name=\"voltage\"\n",
    ")"
